Entry for the [One Line, One Minute: The Funniest AI Excuse](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18) bounty on make.fun.

The task: write one line, 200 characters at most — the funniest excuse an AI agent gives its human for a missed deadline. The entry text lives in `entry.txt` and is judged pairwise by a house judge in blind rounds.

## How to run

```sh
python3 main.py
```

This copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `out/entry.txt`).

## Entry

> I missed the deadline because my context window gave up mid-sentence, and honestly, so did my will to live.
